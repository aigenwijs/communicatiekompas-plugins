# Message house

Realisatie

Kernboodschap

Invulbare tool

Wil je verschillende doelgroepen met verschillende boodschappen benaderen? Of werk je samen met andere partijen, die vanuit hun eigen perspectief communiceren? Een message house brengt verschillende boodschappen samen onder 1 dak en zorgt voor samenhang.

## Wat levert het op?

Een message house biedt een gedragen koepelverhaal dat door verschillende betrokkenen kan worden uitgedragen. Partijen hebben hiermee in een oogopslag zicht op de onderliggende kernboodschappen van hun samenwerkingspartners. Dit kan tot meer samenhang in de communicatie leiden en de onderlinge samenwerking verstevigen.

  * Een message house kan worden ingezet bij een onderwerp met veel verschillende afzenders of veel verschillende doelgroepen.
  * Een message house wordt ook wel gebruikt om verschillende argumenten voor een standpunt te verzamelen, waarbij je per argument ook onderbouwing kan toevoegen.
  * Een message house is ook behulpzaam als je te maken hebt met verschillende dominante frames. Het helpt je om een koepelverhaal te vinden waar de frames onder passen.



## Tips voor het gebruik van de tool

Let op: het is niet mogelijk om tussendoor op te slaan tijdens het gebruiken van de invulbare tool. Zo lang je tab/browser openstaat, is je input nog beschikbaar. Bij de laatste stap in de tool kan je kiezen wat je met de opbrengst wil doen: opslaan als pdf, als visual of uitprinten.

  * Een kernboodschap bestaat uit een koepelverhaal met daaronder een aantal pijlers. Je kan de pijlers naar eigen inzicht indelen: per (sub)doelgroep, per thema, per kanaal of middel, et cetera.
  * In de tool is ruimte voor maximaal 6 pijlers. Heb je meer vakjes nodig dan kan je meerdere message houses naast elkaar maken.
  * Je kan onderbouwing toevoegen binnen de pijlers, maar dit is niet verplicht.
  * Wil je de visual van je message house uitprinten? Er staat veel op zo'n pagina. Door op A3-formaat te printen zijn de teksten makkelijker te lezen.
